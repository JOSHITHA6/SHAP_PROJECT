# 🔍 SHAP Explainability Tool

A Streamlit-based web application to explain machine learning model predictions using SHAP (SHapley Additive Explanations).

---

## 🚀 Features

- Upload your own dataset (CSV)
- Choose task:
  - Classification
  - Regression
- Select ML model:
  - Random Forest
  - Logistic Regression
  - SVM
  - XGBoost
- Generate:
  - Local Explainability (individual prediction)
  - Global Explainability (feature importance)

---

## 🛠 Tech Stack

- Python
- Streamlit (Frontend)
- Scikit-learn (ML models)
- SHAP (Explainability)
- Pandas & NumPy
